# ペット（キューペット）追加の概要

ペットの卵（rotool の「モンスターの卵」）の中間データ `ペット.yaml` を作り、`pet_craft.py` で
`pet.dat.js` の行と、ワンダーエッグバスケットとのセット定義を生成する作業です。
卵そのものは `item.dat.js` には登録しません（ペットは `pet.dat.js` の1行だけです）。

```bash
cd /workspace/ratorio/util/item-card-enchant && python3 pet_craft.py
```

出力は `output_pet.dat.js`（`PET_OBJ` に追記する行）と `output_pet_itemset.dat.js`（`itemset.dat.js` に追記する行）です。
追記先・手順は `/pet-add` コマンド（`.claude/commands/pet-add.md`）に従ってください。

## ペットデータの構造

`engine/equip/pet.dat.js` の `PET_OBJ` は配列リテラルで、**行の添字がそのままペットIDです**（`PET_OBJ[petId]` で直接引かれます）。
行は必ず 0 から欠番なく並べてください。ずれると別のペットの能力が適用されます。`pet_craft.py` は欠番・順序の崩れを検出するとエラー終了します。

```js
[ID,"名前","読み(カタカナ)","説明文",<能力コード,値>…,0],
```

- 能力コードは `item_craft.py` / `card_craft.py` と同じ `buildCapabilityRecord` で生成します（`capabilities` の書式は同じ）
- 「BaseLv100以上の時」の効果は各能力に `at_lv: 100` を付けます（先頭桁が2になる。既存の `2000000000000220,159` など）
- 説明文（`desc`）は画面にそのまま表示されます。能力として表現した効果は自動で説明が出るため `desc` には書かず、
  **計算機で表現できない効果だけ**を書きます。BaseLv条件は自動では付かないので文中に含めます
  （例: `BaseLv100以上の時、<br>　[Mコメット]で受けるダメージ - 50%`）
- ペット選択欄は読み（3番目の値）でソートされます。英字を含む名前は読み上げた読みにします（`Sユンケア` → `エスユンケア`）
- 親密度条件（先頭桁8の旧形式）は新規ペットでは使われておらず、スクリプトも対応していません

## YAML の書式

```yaml
pet_list:
  - name: Sユンケア            # 卵名から「の卵」と末尾の [N] を外した名前
    yomi: エスユンケア
    desc: ...                  # 省略可。計算機で表現できない効果のみ
    capabilities:              # 省略可。書式は item/card と同じ
      - name: 凍結耐性
        value: 100
        at_lv: 100
    wonder_basket: true        # 卵に「ワンダーエッグバスケットと共に装備時」があれば true
```

`wonder_basket: true` のペットには、次の3種類の行が `output_pet_itemset.dat.js` に出力されます。どれが欠けてもセット効果が出ません。

- `w_SE[N] = [4236,4235,-(ITEM_SET_PET_ID_OFFSET + ペットID)];` — セット条件（効果レコード 4236 は全ペットで共有）
- `PetIdToSetIdMap[ペットID] = [N];` — ペット側の逆引き
- `ItemIdToSetIdMap[4235] = ItemIdToSetIdMap[4235].concat([N,…]);` — ワンダーエッグバスケット側の逆引き

効果レコード 4236 は「Atk + 200 , Matk + 200 , 全ての基本ステータス + 10」固定です。
卵の説明に書かれたセット効果の数値が異なる場合、または相手がワンダーエッグバスケット以外の場合は、
このスクリプトでは扱えません（手で定義し、ユーザーに確認してください）。

## 卵の説明文の読み方

| 卵の説明 | YAML |
|---|---|
| 絶対に凍結・氷結・冷凍状態にならない | `凍結耐性` / `氷結耐性` / `冷凍耐性` を value: 100 |
| [スキル名]LvN使用可能 | `スキル使用可能`（skill / skill_lv）。`usableskill.dat.js` に無い組み合わせは `desc` に書く |
| [モンスタースキル]で受けるダメージ - N% | 計算機に無いので `desc` |
| 〜では効果が発揮されず解除されます（攻城戦等） | 登録しない（既存ペットも同様） |
